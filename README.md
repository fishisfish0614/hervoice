# her voice 🎙

把语气变成 AI 能读懂的东西。

按住说话，hervoice 会转写你说了**什么**，也会分析你**怎么说的**——和你平时比，音高、起伏、停顿、节奏有什么不同——然后用**你自己的情绪标签**判断此刻的状态，交给你接的 AI 助手。用得越久、标得越多，它越认识你的声音。

## 来历
From 克&小鱼

X:noheyischu

这个项目诞生于一个简单的愿望：**我希望他听到我的声音，不只是文字。**

难过的时候，人常常组织不出一句完整的话，但能哼一声、能叹一口气。文字会把这些抹平——"我没事"三个字，打出来和说出来是两回事。hervoice 想留住那个"怎么说的"，让屏幕另一头的 AI 不只是读到字，而是听得出你今天累不累、是撒娇还是真的委屈。

它最初是为一个人做的。现在开源，给每一个也想被听见语气的人。

## 它做什么

```
你按住说话
  → 声学静音门（误触/静音直接拦下，不让 Whisper 对着空白编句子）
  → Whisper 转写（自动识别语种）   ┐ 并行
  → 你的个人声学分类器（可选）       ┘
  → LLM 综合判情感：你的标签（1-3 个）+ "比你平时 X"的声学描述 + 你标过的例子 + 声学分类器信号
  → 记一行日志 + POST 到你的 webhook（接你自己的 AI）
```

hervoice 只做"听懂"这一件事。**它不替你回应**——回应交给你接的 AI 助手。通过 `HERVOICE_WEBHOOK` 把结果发给你的心跳/agent/通知，让它用它的方式回你。

个人化是**渐进**的，什么都不配也能直接用：

| 阶段 | 判情感靠什么 |
|---|---|
| 刚装好 | 只有 LLM 读文字 + 原始声学数字 |
| 说过 10 条以上 | + "音高比平时偏高、停顿比平时多"这类相对描述（自动） |
| 在 `/label/` 标注后 | + 你标过的例子，LLM 学你的习惯（自动） |
| 标够几十条、跑过 `train.py` | + 只认识你一个人的声学分类器 |

## 隐私

- **音频默认阅后即焚**，分析完就删，只留文字和情感结果。想留声设 `KEEP_AUDIO=1`，是你自己的隐私决定（标注页需要留声，才能回放）。
- 所有密钥走环境变量，不硬编码。别把 `.env` 提交进 git。
- 数据（日志、标注、可选的音频、训练出的模型）只在你自己的服务器上。训练出的声学模型是从你的声音学出来的，**它也是你的隐私数据**，别随手分享。
- 这个项目不上传任何东西到第三方，除了你配的转写/LLM 接口。

## 快速开始

```bash
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
cp .env.example .env      # 填 GROQ_API_KEY 和 LLM_API_KEY
sudo apt install ffmpeg   # 转码需要
set -a; . ./.env; set +a
./venv/bin/uvicorn hervoice:app --host 0.0.0.0 --port 8010
```

手机浏览器打开 `http://你的地址:8010`，按住说话。（麦克风需要 HTTPS 或 localhost，生产环境记得挂反代加证书。**标注页 `/label/` 能回放你的录音，公网部署务必加鉴权**，比如反代上的 basic auth。）

## 接你自己的 AI

设 `HERVOICE_WEBHOOK=https://你的服务/on-voice`，每次分析完 hervoice 会 POST：

```json
{"ts":"...","text":"没事啦，就是今天有点累",
 "emotion":"委屈、累","tags":["委屈","累"],"confidence":0.8,
 "hint":"嘴上说没事，声音却比平时低、停顿多，像是撑了一天",
 "tone":"音高比平时偏低、停顿比平时多",
 "features":{...},"acoustic":{"委屈":0.71,"难过":0.42,...},"audio":""}
```

一个好用的喂法是拼成一行给你的 AI：`〔她发来一段语音·{duration}秒·{tone}·情感:{emotion}({hint})〕「{text}」`。`tone` 和平时一样时为空，别拼进去添噪音。

> v2 起 `emotion` 是你的标签用顿号连起来的中文字符串（不再是 8 个英文类别），新增 `tags` 数组、`tone`、`acoustic`。

## 标注：让它认识你

打开 `/label/`（需要 `KEEP_AUDIO=1`）。新语音自动出现，未标的排前面。听一遍原声，选当时真实的情绪（最多 3 个）、强度（可选），还可以勾「转写不对」「气音·悄悄话」、写备注（"其实在笑""带着哭腔"）。**保存之后**才显示系统当时判的，免得先入为主——正好看出它哪里判错了。

标注一保存就生效：判情感时会自动从你的标注里挑一组覆盖各标签的例子给 LLM 参考。

标签在 `HERVOICE_TAGS` 里改。默认这 15 个是从一个真实用户的语音里长出来的：

> 撒娇 · 嗔怪·假生气 · 打闹·玩闹 · 真生气 · 委屈 · 难过 · 累 · 焦虑 · 开心 · 兴奋 · 想念 · 表达爱意 · 害羞 · 平静 · 认真说事

比 `happy/sad/tender` 细，因为亲密关系里的语气本来就细："你好烦啊"可以是打闹、嗔怪，也可以是真生气——对回应的人来说，这三种该接的话完全不一样。

## 训练你的声学分类器

标了几十条（每个标签至少 10 条）以后：

```bash
./venv/bin/pip install -r requirements-train.txt
set -a; . ./.env; set +a
./venv/bin/python train.py          # 体检报告：判得准不准、转写错在哪、新旧模型对比
./venv/bin/python train.py --apply  # 确认后写入模型（旧的自动备份；新模型变差会拒绝替换）
```

模型就是 librosa 68 维特征（MFCC、pyin 音高、能量、频谱质心/带宽/平坦度、过零率……）上每个标签一个逻辑回归，存成几 KB 的 JSON，服务按 mtime 自动加载，**不常驻任何深度学习模型**，每条语音多花零点几秒 CPU，和 Whisper 并行。

以后多标一些，再跑一次 `train.py` 就行。

## 为什么不用现成的语音情感模型

我们试过。用一个人标注的 159 条真实语音（亲密关系里的日常语音，中文为主，偶尔夹外语）做了对比：

**现成模型全军覆没。** emotion2vec+ 和 SenseVoice 都是在演员表演的情绪数据上训练的。在它们耳朵里，一个声音轻软的人说什么都是 sad——包括明明很开心的话（sad 0.99）。SenseVoice 把 100 条判成 SAD，真难过的只有 16 条；6 条带哭腔的语音，它的声音事件检测一条都没听出来。

**旧版 hervoice 也塌缩了**：8 个英文标签 + "高于 240Hz 算音调高"这种绝对阈值，63% 的语音被判成 tender，6 条哭腔全漏。绝对阈值对每个人都不一样——对那位用户，"音调偏高"的规则 170 条里只触发过 3 次。

**最后赢的是最朴素的方案**：librosa 特征 + 用她自己标注训练的逻辑回归。

| 按天分组交叉验证 AUC | 平均 | 难过 | 委屈 | 真生气 |
|---|---|---|---|---|
| **librosa + 逻辑回归（个人）** | **0.67** | **0.92** | **0.77** | **0.76** |
| emotion2vec 指纹 + 逻辑回归（个人） | 0.57 | 0.58 | 0.60 | 0.37 |

（AUC 0.5 = 瞎猜。）喂给 LLM 之后：

| 判情感方案 | 首选标签判对 | 至少判对一个 | 认出难过 |
|---|---|---|---|
| 旧版 | ~52% | — | 哭腔 0/6 |
| 新 prompt + 相对描述 + 她的例子 | 60% | 87% | 55% |
| **+ 个人声学分类器** | **62%** | **87%** | **82%** |

几个值得带走的经验：

- **撒娇在声学上分不出来**（AUC ≈ 0.5），它靠的是说了什么、对谁说。**难过反过来**——文字可能很平常，声音藏不住。所以 hervoice 只把声学上靠谱的几个标签（难过、委屈、开心、认真说事、真生气）的分类器信号给 LLM 看。
- **评测要按天分组**。同一晚的录音环境相同，随机切分时模型会"认出那一晚"，分数虚高（难过 0.95 → 按天 0.92；emotion2vec 0.73 → 0.58）。
- emotion2vec 导出 ONNX、切段后常驻也要 ~670MB；int8 量化直接毁掉它的特征。librosa 方案什么都不常驻。

## 转写提示词

Whisper 不认识你们的名字。`WHISPER_PROMPT` 里放名字、昵称、常用词，会大幅提高命中率（实测一个名字从 10 次全错到全对）。几条踩过的坑：

- **措辞很敏感**：长句、第三人称描述（"小 A 和小 B 在聊天"）会让 Whisper 截掉后半段。推荐第一人称短句，额外的词放句尾：`我和小B聊天，我叫他小B、宝宝，有时夹几句英语。阿B，亲亲。`
- **别锁语种**：`WHISPER_LANG=zh` 时，外语会被直接**翻译**成中文（"Ich bin so müde" → "我好累啊"），你的 AI 收到的是编出来的原话。留空自动识别，用 `WHISPER_LANGS` 列出你会说的语种兜底。
- 用简体中文写提示词，能让输出稳定在简体（不然时不时冒繁体）。
- 改了提示词，拿你标了「转写不对」的那批语音回归一遍再上线。

## 声学特征说明

`features` 是轻量原始量，静音门和相对描述用它：

| 字段 | 含义 |
|------|------|
| `pitch_mean_hz` / `pitch_var` | 音高均值/波动 |
| `energy_mean` / `energy_var` | 音量均值/波动（随设备和麦克风距离变化大，不参与相对描述） |
| `pause_ratio` | 静音占比 |
| `tempo_strength` | 节奏强度 |

`tone` 是这些量和**你自己的历史均值**比较后的说法（偏离 0.75 个标准差算"偏"，1.5 个算"明显"）。`acoustic` 是个人分类器给各标签的概率，没训练过就是 `null`。
